# Vidéos de voyage — plan de réalisation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Depuis Fractales, composer un scénario d'étapes (favoris) et en tirer une vidéo `.mp4` de voyage (survol ou latéral, pauses), encodée par FFmpeg.

**Architecture:** Quatre unités sans interface graphique, testées : `Fractal.VideoPath` (trajet entre deux poses), `Fractal.VideoScenario` (étapes, fichier `.fscn`, pose d'une image donnée), `Fractal.VideoEncoder` (FFmpeg par un tube), `Fractal.VideoRender` (fil qui rend chaque image avec `THiResRenderer` vers un flux PNG et la pousse dans FFmpeg). Puis une fenêtre `VideoFrm` et le menu.

**Tech Stack:** Delphi (D2010 via `./build.sh`, CE 13 dans l'IDE), DUnit, FFmpeg externe (`ffmpeg.exe`).

**Spec:** `docs/superpowers/specs/2026-11-07-videos-design.md`

## Global Constraints

- Code compilable sous D2010 (`./build.sh tests|smoke`) et CE 13 ; pas de syntaxe postérieure à D2010.
- Sources UTF-8 avec BOM, CRLF (`./tools/normalize.sh <fichiers>` après toute écriture par script) ; `.dfm` ASCII CRLF, accents en `#nnn`.
- Nouvelles unités déclarées dans `Fractales.dpr` (`uses X in 'src\X.pas'`), `Fractales.dproj` et `tests/FractalesTests.dpr` si testées.
- Messages et commentaires en français, au ton du code existant ; séparateurs `{---…---}` entre routines.
- Formats : carré 1:1 = 1080×1080, 4:5 = 1080×1350, Reel 9:16 = 1080×1920, 16:9 = 1920×1080. Cadence 30 images/s.
- Une seule palette et un seul jeu d'effets pour toute la vidéo : ceux affichés au lancement du rendu.
- Une seule formule (et mêmes paramètres) par scénario.
- Branche `videos` depuis `master` ; commits courts en français, **chacun avec l'accord de JF** ; specs et plans jamais commités.

## Review Focus

1. Zoom profond (largeur ~1e-13) : la pose au début et à la fin d'un trajet doit être exactement l'étape (centre haute précision identique), sans tremblement d'un pixel près des extrémités.
2. Deux étapes identiques ou presque (distance nulle, même largeur) : pas de division par zéro, trajet immobile.
3. FFmpeg absent, ou qui échoue en cours (disque plein, arguments refusés) : message clair avec la fin de son journal, `.mp4` partiel supprimé, aucun processus `ffmpeg.exe` laissé.
4. Annulation au milieu d'un rendu : le fil s'arrête vite, FFmpeg est tué, le fichier partiel est supprimé, l'interface reste utilisable.
5. Scénario rouvert sur une autre machine (tablette) où le favori d'origine n'existe pas : le scénario se charge et se rend tel quel.

- [ ] **Step 1: Tests**

  - `TestEaseInOut` : 0→0, 1→1, 0.5→0.5, croissante sur 11 points.

- [ ] **Step 2:** `./build.sh tests` — échec de compilation (unité absente).

- [ ] **Step 3: Implémenter.** Différence `B − A` par `THighFloat.Sub`, convertie en `TFloat` (dx, dy, d = hypot). Pour le survol, chemin de van Wijk et Nuij avec ρ = √2, en forme stable :
  ```
  b(w0, w1, d) = (w1² − w0² + ρ⁴d²) / (2·w0·ρ²·d) ;  r0 = −ArcSinH(b(w0,w1,d))
  S = longueur totale = (r1 − r0)/ρ avec r1 = ArcSinH(b(w1,w0,d))   [symétrique]
  depuis le départ, après s : décalage u = w0/ρ² · sinh(ρs)/cosh(ρs + r0) ; largeur w = w0 · cosh(r0)/cosh(ρs + r0)
  ```
  Précision : pour s ≤ S/2, poser le centre à `A + (u/d)·(dx,dy)` ; pour s > S/2, évaluer la même formule **depuis B** (w0 := wB, s := S − s) et poser `B − (u/d)·(dx,dy)` — chaque bout garde ainsi la précision de sa propre largeur. Décalage ajouté par `AddFloat(…, FracWordsForPixelSize(w/1000))`. Si d < 1e-9·max(wA,wB) : zoom pur, w = exp(lerp(ln wA, ln wB, f)). Latéral : largeur exp(lerp(ln wA, ln wB, f)), centre interpolé linéairement, même règle des deux moitiés. `EaseInOut` : smootherstep 6f⁵ − 15f⁴ + 10f³. `SuggestedTravelSeconds` : survol 2 + 1.5·S ; latéral d / min(wA, wB) (une largeur d'écran par seconde) ; résultat borné à [2, 30].
